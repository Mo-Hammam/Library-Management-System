# 📚 Library Management System (C++)

## 📌 Overview

This is a console-based Library Management System developed using C++.
The project demonstrates Object-Oriented Programming (OOP) concepts and simulates a real-world library system.

---

## 🚀 Features

* ➕ Add new books with unique IDs
* 📖 Display all books in a formatted table
* 🔍 Search books by:

  * ID
  * Name
  * Author
* 📥 Borrow books (with availability check)
* 📤 Return books
* ❌ Delete books
* 👤 Manage users and track borrowed books
* 💾 Save data using file handling

---

## 🛠️ Technologies Used

* C++
* OOP (Classes, Encapsulation)
* STL (vector)
* File Handling (fstream)

---

## 🧠 Concepts Applied

* Encapsulation (private & public attributes)
* Data validation (unique IDs)
* Searching & sorting algorithms
* Object relationships (User ↔ Book)

---

## ▶️ How to Run

1. Compile the code:

   ```bash
   g++ main.cpp -o library
   ```

2. Run the program:

   ```bash
   ./library
   ```
